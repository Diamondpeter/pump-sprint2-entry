An early-traction buyer for pump.fun paper trading: it buys young coins only once several different people (not the creator) are buying, the creator has not sold, real SOL is building up and the price is still near its create price. It pyramids a little while a coin climbs, cuts losers at -15%, lets winners run on a trailing stop armed at +150%, and takes profit at 8x. Fully deterministic, no clock, no randomness, no environment reads.

## Run it

```sh
node main.ts
```
